## Logic that must not be lost
- **Reading model:** the register grouped by a classification (Class, Building, Room, Asset Account) under a measure (Cost, Accumulated depreciation, Net book value); Table and Donut views of the same grouping; sortable columns; paged rows; the full seven-column table opens in a modal.
- **State fixtures kept:** donut by building, a classification the API does not expose, no fixed assets, state not specified.
- **Open items carried:** % depreciated basis (accumulated over cost vs over depreciable base); replacement-timing data availability; server-side sort; where an asset row should drill to.
